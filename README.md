# Next.js & Supabase Full-Stack Application

![Next.js](https://img.shields.io/badge/Next.js-14%2B-black?style=for-the-badge&logo=next.js)

![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.0-38B2AC?style=for-the-badge&logo=tailwind-css)

A full-stack web application built with **Next.js (App Router)** and **Supabase** for backend services including Authentication, Database, and Storage.

---

## ⚡ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL, Auth, Storage, Realtime)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **ORMs / Clients:** `@supabase/supabase-js`, `@supabase/ssr`
